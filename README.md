# Ритуальная помощь · Екатеринбург

Публичная статическая версия сайта для GitHub Pages. Содержит текущий согласованный дизайн с пегасом, адаптивную верстку и кнопки контактов с обозначенными заглушками.

Локальная разработка: `npm install`, затем `npm run dev`. Публикация: `npm run build`, добавить пустой файл `docs/.nojekyll`, закоммитить папку `docs`. GitHub Pages настроен на ветку `main`, папку `/docs`.

Телефон и ссылка на мессенджер пока не заданы. Форма не отправляет заявки.
